# Mind · 帮乱糟糟的脑子理出头绪

> 一款 iOS 应用的前期调研与产品构思。
> 目标用户：**想法很多，但思维混乱、说不出来、不知道怎么整理的人。**
> 一句话定位：**你只管乱说，它帮你理出头绪、说清楚、做下去。**

调研时间：2026-09。覆盖国内外 60+ 个竞品、相邻品类、GitHub 开源项目、Apple 最新平台能力（iOS 26/27）、中国 AI 合规，以及认知科学研究。

---

## 调研结论速览

1. **"AI 一键生成导图"已经不值钱。** Xmind、Mapify、GitMind 等导图工具全部标配，NotebookLM、豆包、元宝、秘塔、通义听悟等免费提供。这不能是卖点。
2. **大家都在整理"别人的内容"（文档、视频、会议），没人专门整理"我自己脑子里的乱麻"。** 现有 AI 大多在帮你**发散**，而思维混乱的人需要的是**收拢**。
3. **"倒出来 → 被追问 → 理结构 → 说出口 → 去行动 → 连起来"这条闭环没人串起来。**
   - 语音笔记（AudioPen、得到大脑、闪念贝壳）停在"转写 + 润色"；
   - AI 日记（Rosebud、Mindsera）会追问，但不产出结构；
   - 导图工具有结构，但不会问问题；
   - 表达训练（Yoodli）和整理完全割裂。
4. **国内最近的对手是得到大脑和闪念贝壳**，两者都在从"记录工具"转向"思考伙伴"——方向被验证了，留给差异化的时间大约 6–12 个月。
5. **需求真实存在**：豆瓣"文字失语者互助联盟"有 38 万+ 成员；知乎"想法很多但表达不出来"类问题十几年长盛不衰；用户在自己拼"DeepSeek + Xmind"工具链。
6. **研究支持的设计方向**：自己构建导图比看现成的图效果好（g=0.72 vs 0.43）；给候选比让人从零想容易；"先用 AI 再自己想"会降低原创性——所以 **AI 应该先问后答、整理用户的原话，而不是替用户生成**。
7. **技术上今年是好时机**：iOS 26 的端侧转写（免费、离线）和端侧模型，iOS 27 新增对小开发者免费的 Apple 私有云模型（32K 上下文）。但**国行设备要按"没有 Apple 端侧 AI"设计**，中国版走已备案的国产模型。
8. **中国上架需要公司主体 + App 备案 + 生成式 AI 登记 + 内容标识**，约 2–4 个月。建议先在海外华语店面首发，同时办理国内合规。

## 产品核心：一个闭环

```
① 倒出来      ② 被追问         ③ 理结构        ④ 说出口          ⑤ 去行动       ⑥ 连起来
按住说话  →  一次只问一个  →  边说边长的导图  →  一键成稿        →  下一步行动  →  "你以前也想过"
想到哪说哪   "你是不是想说…"   你是作者，AI 整理   30 秒 / 3 分钟    提醒事项      每周回顾
             3 个候选任你选    原话可追溯          说出来练习 + 反馈
```

**差异化**：从"我的乱想"出发 · 追问 + 候选表述 + 收拢 · 原话溯源 + 你的口吻 · 导图 → 讲稿 → 练习的表达闭环 · 长期思维档案 · 隐私优先 · 中文场景深耕。

## 建议的下一步

1. **先别急着写代码**——用 2–3 周做低成本验证：10–15 个用户访谈 +"绿野仙踪"测试（用户在微信里发语音，你用 AI 手动整理成导图 + 一个追问 + 30 秒讲稿发回去）+ 小红书内容测试。
2. 测 50 段真实中文倾诉录音的转写质量，定下语音方案。
3. 验证通过后做 MVP：只做"倒 → 问 → 理 → 说"，3 个场景入口，原生 SwiftUI。
4. 如果要上中国大陆店面，**现在就启动公司注册和备案**。
