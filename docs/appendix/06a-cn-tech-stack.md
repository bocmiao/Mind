## 0. 结论速览

1. **云端 ASR 是中国版最大的一项可变成本。** 每月 3 小时语音，低价档 ¥2.4–3.6（含火山资源包价；已更正：原记 ¥2.6–3.6），讯飞大模型版 ¥6.0–14.85 ✓。只算模型时是 ¥0.13–0.63（07 §3.2 ✓），ASR 是它的约 4–114 倍，只看低价档约 4–27 倍（计算；已更正：原记"5–100 倍"）。**07 §3.2"付费用户的 AI 成本占比多数在 10% 以内"只在转写走端侧时成立**（推断，依据 §5.3）。
2. **云端 ASR 兜底首选火山"豆包流式语音识别模型 2.0"或腾讯"实时语音识别（大模型 2.0 版）"，后付费都是 ¥1/小时 ✓。** 火山可以直接传热词（双向流式约 100 token），还能传 ≤800 token、≤20 轮的上下文 ✓（例如当前导图的节点，推断）。阿里 Fun-ASR 实时版 ¥0.00033/秒，约 ¥1.19/小时，支持热词 ✓。Paraformer 最便宜（¥0.864/小时）✓，但阿里官方称它是"较早一代"，建议迁到 Fun-ASR 或 Qwen-ASR ✓。【核查补充】阿里选型页当前把 **qwen-audio-3.1-asr-flash-streaming** 列为实时识别首选，按 token 计费，草稿漏了（见 §1c）。
3. **审核按次计费，调用频率比单价更要紧。** 阿里大模型输入/输出审核 ¥15/万次 ✓，腾讯文本内容安全 ¥25/万条 ✓。如果"边说边长"每句话都送审（按每月 3,600 次算），审核费 ¥5.4–9.0/月（计算），超过模型费。**应当按停顿批量送审（推断）。**
4. **docs/06 §4 的 ops 协议能稳定落地，但厂商之间差异大：**
   - 严格 JSON Schema（`response_format: json_schema` + `strict`）：通义只有 Qwen3.7-Plus、Qwen3.7-Flash、Qwen3.7-Max、Qwen3.8-Flash、Qwen3.8-Max 系列支持 ✓（已更正：原记"Qwen3.7/3.8 系列"，范围写宽了）；豆包 Seed 2.0 支持，但仍是 beta ✓。
   - DeepSeek 官方 API 只有 `json_object`，严格约束只能走"strict 工具调用"，也是 Beta ✓。
   - 智谱结构化输出文档里只有 `json_object` ✓。
   - 深度 ≤4、每轮最多一个 `ask`（06 §4.2 ✓）、节点约 12 字（06 §4.3 ✓）这类约束，Schema 表达不了或厂商明确不支持（DeepSeek 不支持 minLength/maxLength、minItems/maxItems ✓；通义、豆包的关键字清单也没列这些 ✓），**§4.2 的应用前校验和重试不能省。**
5. **端侧小模型从速度和许可证看可行，合规上暂不可行：**
   - Qwen3 / Qwen3.5 / MiniCPM5 都是 Apache-2.0 ✓。
   - iPhone 17 Pro 上 Qwen3-1.7B（MLX 4bit）约 65 token/秒，Qwen3-4B 约 28 token/秒 ✓。
   - 持续推理会发热降速：同一基准用 Gemma 4 E2B 测，**MLX 约 60 秒内掉过一半，LiteRT-LM 约 4 分钟才掉过一半** ✓（已更正：原记"GPU 持续推理约 60 秒内掉速一半"，把 MLX 的结果套到了所有 GPU 运行时，且测的不是 Qwen）。
   - 网信办 2026-07-15 公告"Apple智能"等 7 款"手机端侧生成式人工智能服务"完成备案 ✓（已更正措辞：原记"纳入备案管理"）。**第三方 App 在本机跑开源模型对公众生成内容，应走备案还是登记，没有公开口径（待核实：两份公告都没提）。**
6. **每个活跃用户每月的成本（推断）**：端侧转写约 ¥0.40–0.90；云端 ASR 低价档约 ¥4.1–5.5（占 ¥15.8 净收入的 26–35%）；贵的组合约 ¥24.1–27.0，超过净收入（计算 ✓）。【核查补充】¥15.8 按 12% 佣金算；07 §3.2 注明 12% 只适用于小企业计划或订阅第二年起，按标准 25% 净收约 ¥13.5 ✓，此时云端低价档占 30–41%（计算）。
