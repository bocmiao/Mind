## 2. 中国大陆 AI 应用合规

### 2.1 规则框架（待核实原文）

- **《生成式人工智能服务管理暂行办法》**（2023-08 施行）：提供者承担内容生产者责任；须有服务协议、投诉举报机制、未成年人保护措施；不得非法留存可识别身份的输入记录。
- **"备案"与"登记"的区别**：
  - 自研或训练大模型对外服务 → 国家网信办**备案**；
  - **通过 API 调用已备案模型的应用 → 属地网信办登记**，获得上线编号；上线后须在显著位置公示所用模型名称和备案号/上线编号。
- **《人工智能生成合成内容标识办法》**（2025-09-01 施行，配套强制国标 GB 45438-2025）：
  - 文本在开头、末尾、中间或界面周边加**显式提示**；
  - **下载、复制、导出的文件须带显式标识**——"导出表达稿"是重点；
  - 文件元数据须写隐式标识；
  - 用户协议写明标识方式。
- **《个人信息保护法》**：倾诉内容很可能涉及健康、心理等**敏感个人信息**，需要单独同意并做影响评估；数据出境须单独同意。
- **情感陪伴类规则**：2025-12 网信办就《人工智能拟人化互动服务管理暂行办法》征求意见，涉及情感依赖和未成年人保护（现状未知）。**产品定位应避开"AI 伴侣 / 心理疏导"。**

### 2.2 一个开发者要做的事（估算周期）

| 步骤 | 内容 | 周期 |
|---|---|---|
| 1 主体 | 注册有限公司（登记普遍只受理单位主体）；Apple 组织账号需要 D-U-N-S 编码 | 1–4 周 |
| 2 备案 | 境内服务器 + 域名 ICP 备案；**App 备案**（通过云服务商提交，需要包名、签名公钥等） | 各 1–3 周 |
| 3 模型接入 | 选已备案的国产模型，签调用协议；服务端接入输入/输出内容审核 | 1–2 周 |
| 4 登记 | 登记表、安全自评估报告、测试题库与拒答率、关键词库、用户协议与隐私政策、标识方案、投诉与未成年人保护机制、应急预案 | 1–3 个月，常需补正，各省口径不一 |
| 5 产品改造 | 模型备案号/上线编号公示页；显式 + 隐式标识；敏感信息单独同意；日志留存；未成年人模式 | 与上面并行 |
| 6 上架 | App Store Connect 填 ICP 备案号，备好登记证明应对审核 | — |

**总体约 2–4 个月，难度中高；个人开发者基本走不通。**

### 2.3 常见坑

- 用未备案的境外模型（OpenAI、Claude、Gemini）服务境内用户——同时触碰合规和数据出境；
- 客户端直连模型 API；
- 只做了 App 备案、没做登记；换模型厂商后没有变更登记；
- 导出文件缺标识；没公示模型备案号；
- 把"倾诉"包装成心理咨询；
- 以为端侧跑开源模型就能规避——对公众提供生成服务的合规定性并不清楚。

### 2.4 建议的市场节奏

两份调研给出的建议有张力：国内调研认为"需求证据在国内最强，应先在国内验证"，合规调研认为"中国版要等登记完成"。合并后的建议是：

1. **验证阶段用国内用户**：访谈和"绿野仙踪"测试（人工用 AI 帮用户整理，不上架 App）不涉及上架合规，可以马上在国内做。
2. **同时启动公司注册、备案和登记**（2–4 个月）。
3. **首发地区选中文用户多、不需要登记的店面**：香港、台湾、新加坡、马来西亚、北美、澳洲的华语用户，中文界面 + 海外模型 / Apple 端侧与 PCC。
4. **登记完成后上中国大陆店面**，国内版切换到已备案的国产模型。

国内价格变动频繁，**以各厂商官方价格页为准**。

### 3.2 每个活跃用户每月的 AI 成本

假设：每天 3 次、每次约 3k 输入 + 1k 输出 token → 每月约 27 万输入 + 9 万输出 token。

| 模型档位 | 每用户每月 |
|---|---|
| 国产低价档（qwen-flash、豆包 mini、DeepSeek Flash 闲时） | 约 ¥0.2–0.9 |
| 国产中档（qwen-plus、豆包 lite） | 约 ¥0.4–0.5 |
| 海外低价档（Gemini Flash-Lite、gpt-5-nano 等） | 约 $0.05–0.2 |
| Claude Haiku 4.5 / Sonnet 5 | 约 $0.72 / $1.44 |
| 海外版主要走端侧 + PCC | 接近 $0 |

**修正系数**：

- 追问历史累积、推理 token，会让实际成本达到上表的 2–5 倍；
- 系统提示词走缓存，可省 20–40% 输入费用；
- 重度用户按 5–10 倍估算。

**结论**：以 ¥18/月订阅、12% 佣金计，净收约 ¥15.8，**付费用户的 AI 成本占比通常低于 10%**。真正的成本来自**免费用户**——所以免费档的云端 AI 额度要有上限，能端侧做的尽量端侧做。

## 4. 商业模式

### 4.1 免费 + 订阅 + 买断

| 档位 | 内容 |
|---|---|
| **免费** | 手动导图、大纲、捕获不限量；端侧转写；每月一定分钟数的 AI 整理（用"可整理多少分钟"表述，而不是 credits）；导出 PNG/Markdown |
| **Pro 订阅** | 更多 AI 整理额度；追问与候选表述不限；成稿全部格式；说出来练习；每周回顾；"你以前也想过"；私密导图的端侧优先整理 |
| **终身买断** | 覆盖 Pro 功能 + 每月固定 AI 额度（控制长期成本） |
| **（以后）训练营 / 场景包** | 21 天表达训练、面试/述职/答辩场景包，一次性购买 |

### 4.2 定价参考

| 市场 | 月付 | 年付 | 终身 |
|---|---|---|---|
| 中国（需 A/B） | ¥18 | ¥128–168 | ¥298–398 |
| 海外 | $5.99–7.99 | $39.99–59.99 | $99–149 |

**锚点**：国内年费不宜超过 ¥199（避免和得到大脑、讯飞正面相撞，flomo ¥99 是心理锚）；海外 AI 日记类 $75–130/年、MindNode $24.99/年、Xmind Pro 约 $59/年。

### 4.3 增长渠道

- **小红书（主阵地）**："乱想 → 30 秒说清楚"的前后对比视频；竖版导图分享卡片（每张分享都带水印和 App 名）。
- **知乎长尾**："想法很多但表达不出来"一类问题常年有流量。
- **社群**：豆瓣"文字失语者互助联盟"（38 万+ 成员）招募内测、做共创。
- **少数派 / Mergeek / Apptisan**：独立开发者访谈 + 福利价。
- **Apple 编辑推荐**：Tiimo 凭温和、可视化、低压力的设计拿下 2025 年度 iPhone App——认真做无障碍、动态字体、Liquid Glass 适配，主动提交推荐申请。
- **海外**：ADHD 社群、Product Hunt、"verbal thinkers"人群。

## 5. 路线图

### 阶段 0：低成本验证（2–3 周，不写 App）

| 动作 | 做法 | 通过标准（建议） |
|---|---|---|
| **用户访谈** | 10–15 位目标用户（豆瓣小组、小红书、身边朋友）。问：最近一次"脑子很乱/说不出来"是什么时候？当时怎么办的？用过哪些工具？为什么放弃？ | 能归纳出 3 个以上高频场景 |
| **"绿野仙踪"测试** | 10 位用户用一周：他们在微信里发语音给你，你用 AI（按本文档的提示词思路）整理成导图 + 一个追问 + 30 秒讲稿发回去 | ≥ 40% 的人在没有提醒的情况下用了 3 次以上；≥ 30% 表示愿意每月付 ¥18 |
| **内容测试** | 在小红书发 5–10 条"乱想 → 导图 → 说清楚"的演示视频 | 收藏率、评论里"求链接"的数量；等候名单人数 |
| **中文转写测试** | 50 段真实中文倾诉录音，对比端侧与云端转写的字错率 | 选定转写方案 |

**同时启动**：公司注册、ICP 备案、App 备案、登记材料准备（如果打算上中国大陆店面）。

### 阶段 1：MVP（单人全职约 8–12 周，估算）

**只做核心闭环：倒 → 问 → 理 → 说。**

| 模块 | MVP 范围 |
|---|---|
| 入口 | 3 个场景：🌀 脑子好乱、⚖️ 纠结一件事、🎤 想说清楚 + 自由模式 |
| 捕获 | 按住说话 / 打字；端侧实时转写；**边说边长** |
| 整理 | AI 归类、合并、提炼中心问题；**复述确认**；原话/AI 分色；原话溯源（文字） |
| 追问 | 一次一问 + **候选表述**；可跳过 |
| 编辑 | 原生导图（1 种布局）+ 大纲视图 + iPhone 聚焦视图（一次一层）；拖拽、折叠、撤销 |
| 表达 | 一键成稿：一句话 / 30 秒 / 3 分钟 / 一条消息 |
| 行动 | 下一步最小行动 |
| 数据 | 本地存储 + iCloud 同步；导出 PNG / Markdown |
| 信任 | 第三方 AI 同意页；透明额度；危机护栏；App 锁 |

**不在 MVP**：协作、白板、文档/视频总结、Mac/Vision Pro、训练营。

### 阶段 2：内测（4–6 周）

- TestFlight 50–200 人（来自等候名单）；
- 每周看：首张导图生成时间、AI 节点采纳率、追问回答率、成稿导出率、7 日留存；
- 每周人工抽检 20 条 AI 输出，更新评估集。

### 阶段 3：首发与迭代（v1.1–v1.3）

| 版本 | 重点 |
|---|---|
| v1.1 | **说出来练习**、模拟提问、语气检查；锁屏小组件、操作按钮、控制中心入口 |
| v1.2 | 更多场景（有个想法、想写点什么、复盘、聊完整理、心里不舒服）；框架一键套用 + 空格高亮；三筐分拣 |
| v1.3 | "你以前也想过"、每周回顾、想法孵化器；Siri / 快捷指令；分享卡片模板 |
| 之后 | iPad + Pencil、Mac、对话彩排、表达训练营、分歧地图、思维图谱 |

## 6. 主要风险与对策

| 风险 | 可能性 | 影响 | 对策 |
|---|---|---|---|
| AI 生成的结构"不是我的想法" | 高 | 高 | 原话优先、AI 内容分色认领、先问后答；把幻觉率纳入评估 |
| 大厂一个版本就跟进单点功能 | 高 | 中 | 不拼单点，拼闭环 + 个人上下文 + 中文场景深度；速度和口碑 |
| 竞品时间窗：语音笔记类正在往"结构化输出"走 | 中 | 中 | 6–12 个月内把"追问 + 表达"做出口碑 |
| 中国合规周期长、个人主体走不通 | 高 | 高 | 先海外华语店面首发，并行办理合规 |
| 免费用户的 AI 成本 | 中 | 中 | 端侧优先、按分钟的免费额度、缓存 |
| 情绪/心理健康边界 | 中 | 高 | 不做治疗宣称；危机护栏；不做"AI 伴侣" |
| 用户新鲜感过后流失 | 高 | 高 | "说出来练习"和每周回顾做留存；"睡前清空""每日 60 秒"等轻习惯；不做惩罚式打卡 |
| 端侧模型/系统更新导致行为漂移 | 中 | 中 | 评估集回归；关键提示词版本管理 |
